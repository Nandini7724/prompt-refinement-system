# Prompt Refinement System

## Overview
This project implements an iterative prompt refinement system for text-to-image generation using Stable Diffusion. The system compares Smart Refinement and Dumb Refinement approaches using CLIP Score and Aesthetic Score evaluation metrics.

## Features
- Text-to-image generation using Stable Diffusion
- Smart vs Dumb prompt refinement
- Multi-iteration refinement pipeline
- CLIP Score evaluation
- Aesthetic Score evaluation
- Interactive frontend using Gradio

## Tech Stack
- Python
- Stable Diffusion
- BLIP
- Gradio
- PyTorch
- Transformers

## How to Run
1. Install dependencies
2. Run all notebook cells
3. Launch the Gradio UI
